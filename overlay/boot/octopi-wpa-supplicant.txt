## OctoPi x86 — WiFi Setup
## ============================================================
## Edit this file on Windows BEFORE first boot to set your WiFi.
## The boot partition (this drive) is readable from Windows Explorer.
##
## INSTRUCTIONS:
##   1. Open this file in Notepad
##   2. Fill in your SSID and PSK below
##   3. Save the file
##   4. Safely eject the USB / SD card
##   5. Insert into Compute Stick and power on
##
## On first boot, OctoPi will read this file and connect to WiFi.
## After that, reach it at:  http://octopi.local
## ============================================================

## -- Your WiFi credentials --
## Replace "Your_Network_Name" and "Your_WiFi_Password" below:

network={
    ssid="Your_Network_Name"
    psk="Your_WiFi_Password"
    key_mgmt=WPA-PSK
}
